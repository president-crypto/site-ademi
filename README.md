# ADEMI - Association pour le Développement Économique et la Mobilité Internationale

Ce dépôt contient le site internet officiel de l'association **ADEMI**, basée à Poitiers, migré de Squarespace vers Hostinger. Le site est développé avec **React**, **Vite** et **Tailwind CSS**.

---

## 📢 Informations Clés & Agréments

### 🤝 Agrément Service Civique
L'association **ADEMI** dispose de l'agrément officiel pour accueillir des volontaires en **Service Civique**. 

* **Mission Principale :** *« Développer l'accès aux droits pour tous »*
* **Objectif :** Cette mission occupe une place centrale au sein de l'association et du site web, visant à accompagner les publics dans la connaissance et l'exercice de leurs droits fondamentaux et socio-professionnels.

---

## 🛠️ Stack Technique

* **Framework :** React 19 + Vite 7
* **Styling :** Tailwind CSS 4
* **Icônes :** Lucide React
* **Déploiement :** Automatique sur Hostinger via GitHub Actions (`deploy.yml`) à chaque push sur la branche `master`.

---

## 🚀 Développement Local

1. Installez les dépendances :
   ```bash
   npm install
   ```
2. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```
3. Compilez pour la production :
   ```bash
   npm run build
   ```
